# 0922 作业③：还可以给模型什么外挂？

> 学号：f25011102 ｜ 日期：2026-10-02

模型（尤其是本地模型）本身只会"输入→输出"，能力上限由参数决定。给它加"外挂"，就是让它在**模型能力之外**获得记忆、知识、工具、多模态等扩展能力。按课程体系梳理如下：

## 一、外挂总览（8 类）

| 外挂 | 解决什么问题 | 本质 | 课程对应 |
|---|---|---|---|
| 1. 工具调用（Function Calling） | 让模型能"做事"而非只"说话" | 模型输出结构化工具名+参数，程序执行后回传结果 | 0922 作业①（命令执行 Agent） |
| 2. MCP（Model Context Protocol） | 统一接入外部工具/数据源的开放协议 | 一套标准，让任意模型连任意工具（文件、数据库、浏览器……） | 0929 开源框架课 |
| 3. RAG / 知识库 | 模型不懂"你的资料"，还爱编造 | 检索增强：先查资料再回答，可溯源 | 0920 开源模型部署课 |
| 4. Skill 插件 | 给 Agent 配"说明书"，按需调用 | SKILL.md = 何时用什么命令的文档，模型读到就会用 | 0920 安装 skills 课 |
| 5. 记忆（Memory） | 模型无状态，记不住上次聊了什么 | 外部保存会话/长期记忆，下次拼进上下文 | 视频 step2（messages 历史） |
| 6. 联网搜索 | 模型知识有截止日期 | 搜索 API 结果作为上下文喂给模型 | 0929 假期作业（news skill） |
| 7. 多模态输入 | 只能读文字 | 图片/音频/视频转成 token 一起输入 | 开源框架（dashscope 等） |
| 8. 提示词工程 / 模板 | 同样模型，不同表现 | 写好 system prompt = 免费"外挂" | 0915~0922 全程 |

## 二、重点展开（课程相关）

### 1. 工具调用（Function Calling）—— 让模型长出手脚
模型不直接执行命令，而是输出 `{"name": "run_command", "arguments": {"cmd": "ls"}}`，由你的程序执行并回传结果。这就是视频里"命令：/完成："协议的"正式版"。

```python
# 伪代码：定义工具
tools = [{"type": "function", "function": {
    "name": "run_shell", "description": "执行一条shell命令",
    "parameters": {"type": "object", "properties": {"cmd": {"type": "string"}}}}}]
# 模型决定是否调用，程序执行，结果回传，循环直到模型不再要工具
```

### 2. MCP —— 工具的"USB-C 接口"
以前每接一个工具写一套代码；MCP 把"文件、数据库、浏览器、Slack……"都变成统一协议下的 server，模型侧用同一套工具调用方式。**一次实现，处处复用**，是 2026 年 Agent 生态的事实标准。

### 3. RAG / 知识库 —— 给模型"查资料"
流程：文档切块 → 向量化 → 存向量库 → 提问时检索 Top-K 片段 → 拼进 prompt。解决"模型不知道你的私有资料"和"幻觉"两大痛点。

### 4. Skill —— 给模型"说明书"（本课重点）
一段 `SKILL.md` 就是一份外挂：告诉模型"遇到 XX 情况，用 XX 命令"。比如天气 skill、新闻 skill。**不是你给模型装了 skill 它才厉害，而是它按你的说明书调了工具**（视频原话："不是它厉害，而是你厉害"）。

### 5. 记忆 —— 让模型"记得住"
- 短期：把 messages 历史一直带着（视频 step2）；
- 长期：把对话摘要/用户画像存进数据库，下次拼进 system。

### 6. 联网搜索 —— 让模型"不过期"
```bash
# 新闻 skill（视频同款）
curl -L -A "Mozilla/5.0" "https://news.google.com/rss/search?q=AI&hl=zh-CN&gl=CN&ceid=CN:zh-Hans"
```

## 三、结论

> **模型的"外挂"本质只有一个：把更多上下文和工具交给它。**
> 上下文（知识库、记忆、搜索、prompt）× 工具（函数、MCP、Skill）＝ 更强的 Agent。
> 这也正好是《ai-agent-book》的核心公式：**Agent = LLM + 上下文 + 工具**。
