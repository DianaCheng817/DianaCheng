■ 格子：不同方式调用的区别（Ollama API / OpenAI Chat Completions / OpenAI Responses / Anthropic Messages）
已完成，要点：
- Ollama API：本地推理引擎原生接口（/api/generate、/api/chat），返回带推理性能指标，最适合本地/离线/不花钱；
- OpenAI Chat Completions：事实标准（/v1/chat/completions，messages 数组，无状态），兼容性最广，Ollama 内置兼容层可直接跑；
- OpenAI Responses：新一代状态化接口（/v1/responses，input+tools+store），服务端管上下文，面向 Agent 多步工具调用；
- Anthropic Messages：Claude 系专用（/v1/messages，system 独立字段，content 块数组），长上下文与流式体验好；
选型：本地→Ollama API；通用/切换→Chat Completions；Agent 任务→Responses；Claude 系→Messages。
详细对比见 D:\开源微专业作业\0922_ollama\02_不同方式调用的区别.md。
