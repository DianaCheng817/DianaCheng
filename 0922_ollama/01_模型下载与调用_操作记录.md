## 三、模型调用（本地实测输出）

### 方式 1：命令行 CLI

```bash
ollama run qwen3:0.6b "用一句话介绍你自己"
```

### 方式 2：Ollama 原生 API `/api/generate`（实测）

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:11434/api/generate `
  -Method Post -Body '{"model":"qwen3:0.6b","prompt":"用一句话介绍你自己","stream":false}'
```

实测返回：

```json
{
  "model": "qwen3:0.6b",
  "response": "我是一名拥有XX专业背景的资深人员……",
  "total_duration": 13898000,   // ≈13.9 秒（小模型本机推理，无 GPU）
  "eval_count": 271
}
```

### 方式 3：Ollama 原生 API `/api/chat`（多轮对话，实测）

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:11434/api/chat `
  -Method Post -Body '{"model":"qwen3:0.6b","messages":[{"role":"user","content":"1+1等于几？"},{"role":"assistant","content":"等于2。"},{"role":"user","content":"那再加1呢？"}],"stream":false}'
```

实测返回：`1+1等于2。如果继续加1的话，就是2+1=3……`

### 方式 4：OpenAI 兼容接口 `/v1/chat/completions`（实测）

Ollama 自带 OpenAI 兼容层，任何 OpenAI SDK 改 `base_url` 即可调用：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:11434/v1/chat/completions `
  -Method Post -Body '{"model":"qwen3:0.6b","messages":[{"role":"user","content":"你好！"}],"stream":false}'
```

实测返回 `choices[0].message.content` 及 `usage: {prompt_tokens:12, completion_tokens:176, total_tokens:188}`

> 完整可复现脚本见同目录 `call_ollama_demo.py`（用 urllib 调原生 API + OpenAI 兼容接口）。

## 四、对外服务（把 Ollama 变成可被外部调用的服务）

默认 Ollama 只监听 `127.0.0.1`（仅本机可访问）。"对外服务"有两种做法：

### 方案 A：局域网内对外（推荐，改动最小）

1. 设置环境变量 `OLLAMA_HOST=0.0.0.0:11434`（系统属性 → 环境变量，或 `setx OLLAMA_HOST "0.0.0.0:11434"`）；
2. 重启 Ollama（托盘图标退出后重新打开，或重启 ollama 服务）；
3. 同局域网设备即可访问 `http://<本机IP>:11434`，例如手机/另一台电脑：
   ```bash
   curl http://192.168.x.x:11434/api/tags
   ```

### 方案 B：公网访问（演示/临时分享用）

用内网穿透工具把 11434 端口暴露到公网：

```bash
# 方式1：cloudflared（免费，无需注册公网IP）
cloudflared tunnel --url http://127.0.0.1:11434

# 方式2：ngrok
ngrok http 11434
```

拿到公网地址后，任何人都能按 `https://xxxx.trycloudflare.com/v1/chat/completions` 调用你的模型服务。

> 安全提醒：对外暴露后任何人都能调用你的模型、消耗你的算力，演示完请及时关闭隧道。
